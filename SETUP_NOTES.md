# Setup notes – PM_Interaction_Tool

How this project is set up and run on Windows, written so the same setup can be reused in a
new project. Recorded 2026-10-16.

---

## 1. Folder layout (what matters for running)

```
PM_Interaction_Tool\
├── .venv\                      Python virtual environment (inside the project folder)
├── main.py                     entry point of the original P-M desktop app
├── run_app.bat                 run the P-M app from source
├── build_exe.bat               build the P-M app as a folder-mode .exe
├── run_column_tool.bat         run the STAAD-linked column design tool
├── requirements.txt            original app packages (see §3 for the full list)
├── src\                        P-M engine + IS 456 column check (src\design\column_check.py)
├── column_tool\                column tool window, groups, report generator
│   └── __main__.py             makes "python -m column_tool" work
├── staad_link\staad_reader.py  read-only OpenSTAAD link (uses MySTAADLibrary)
├── MySTAADLibrary\mystaad\     the user's own OpenSTAAD wrapper library
├── design_docs\                EDRC Excel sheet builders, sample sheets, BACKLOG.md
│   ├── build_circular_doc.bat
│   └── build_rect_doc.bat
├── tests\                      pytest suite
└── staad file\Column.STD       test STAAD model
```

Every .bat file starts with `cd /d "%~dp0"` (or `"%~dp0.."`), so it works when double-clicked
from Explorer and from any current folder. All of them call the venv's Python directly
(`.venv\Scripts\python.exe`), so nothing needs to be "activated" first.

## 2. The .bat files

### 2.1 `run_app.bat` – run the original P-M app from source

```bat
@echo off
REM Run the app from source (use this while developing).
cd /d "%~dp0"
".venv\Scripts\python.exe" main.py
if errorlevel 1 pause
```

Starts the PySide6 desktop app (`main.py`). Always runs the latest code; no build step.
`if errorlevel 1 pause` keeps the console open when the app crashes, so the error is readable.

### 2.2 `build_exe.bat` – build the P-M app as an .exe (folder mode)

```bat
@echo off
REM Rebuild dist\PM_Interaction_Tool\PM_Interaction_Tool.exe (folder mode).
REM Run from anywhere; requires the .venv created during setup.
cd /d "%~dp0"

".venv\Scripts\python.exe" -m PyInstaller main.py ^
    --name PM_Interaction_Tool ^
    --onedir ^
    --windowed ^
    --noconfirm ^
    --clean ^
    --exclude-module PySide6.QtWebEngineCore ^
    --exclude-module PySide6.QtWebEngineWidgets ^
    --exclude-module PySide6.QtPdf ^
    --exclude-module PySide6.Qt3DCore ^
    --exclude-module pytest ^
    --exclude-module mypy

if errorlevel 1 (
    echo.
    echo BUILD FAILED
    pause
    exit /b 1
)
echo.
echo Done: dist\PM_Interaction_Tool\PM_Interaction_Tool.exe
```

Builds `dist\PM_Interaction_Tool\PM_Interaction_Tool.exe` with PyInstaller (about 90 s,
about 160 MB).

- `--onedir`: a folder build. It starts faster than a single file, and you copy the whole
  folder to share it.
- `--windowed`: no console window.
- `--clean`, `--noconfirm`: fresh build, overwrites the old one.
- `--exclude-module …`: leaves out unused Qt modules and dev tools to keep the build smaller.
- The .exe is a snapshot of the code. It does **not** pick up code changes until you run this
  .bat again.

### 2.3 `run_column_tool.bat` – the STAAD-linked column design tool

### .bat patterns worth reusing

| Pattern | Why |
|---|---|
| `cd /d "%~dp0"` | run from the .bat's own folder, so double-clicking works (`/d` also switches drive) |
| `".venv\Scripts\python.exe"` in quotes | uses the project's venv, no activation; quotes handle spaces in paths |
| `python -m package` | runs a package with a `__main__.py`, so imports resolve from the project root |
| `if errorlevel 1 pause` | console stays open on a crash so you can read or copy the error |
| `exit /b 1` after a failure | returns a non-zero code if another script calls this .bat |

## 4. Connection to STAAD.Pro (OpenSTAAD)

| Item | Value |
|---|---|
| STAAD version | STAAD.Pro CONNECT Edition **22.00.00.15** |
| Installed at | `C:\Program Files\Bentley\Engineering\STAAD.Pro CONNECT Edition\` |
| COM ProgID | **`StaadPro.OpenSTAAD`** (registered by the STAAD install) |
| Python library | `pywin32` (`win32com.client`, `pythoncom`) |
| Wrapper | the user's `MySTAADLibrary\mystaad` (class `OpenSTAAD`) plus `staad_link\staad_reader.py` |

How it attaches. STAAD must already be open with the model loaded:

```python
win32com.client.GetObject(None, "StaadPro.OpenSTAAD")     # MySTAADLibrary
win32com.client.GetActiveObject("StaadPro.OpenSTAAD")    # equivalent
```

`staad_reader.py` adds the folders to `sys.path` itself, so no settings are needed:

```python
sys.path.insert(0, ROOT)                                   # project root (src, column_tool)
sys.path.insert(0, os.path.join(ROOT, "MySTAADLibrary"))   # so "from mystaad import OpenSTAAD" works
```

OpenSTAAD calls used (all **read-only**: no analysis is run and nothing is written to the model):

| Purpose | Call |
|---|---|
| selected members | `Geometry.GetNoOfSelectedBeams`, `Geometry.GetSelectedBeams` |
| length | `Geometry.GetBeamLength` (via MySTAADLibrary) |
| section type | `Property.GetBeamSectionPropertyRefNo` → `Property.GetSectionPropertyType` (671 = circle, 672 = rectangle) |
| sizes | `Property.GetBeamProperty` → width = ZD, depth = YD, in **metres** (converted to mm and rounded to 0.1 mm) |
| beta angle | `Property.GetBetaAngle` |
| load cases | `Load.GetPrimaryLoadCaseCount/Numbers`, `Load.GetLoadCombinationCaseCount/Numbers`, `Load.GetLoadCaseTitle` |
| forces along a member | `Output.GetIntermediateMemberForcesAtDistance` (local axes, compression +ve) |
| results present | `Output.AreResultsAvailable` |
| model file | `GetSTAADFile` (8.3 short path, converted with `win32api.GetLongPathName`) |
| units | `GetBaseUnit` (2 = metric, required) |

OpenSTAAD gotchas found in this project:

1. **Mark functions as methods.** Late-bound COM treats them as properties otherwise:
   `obj._FlagAsMethod("GetBeamLength")`.
2. **Fetch sub-objects once and keep them.** Each `root.Output` access returns a *new* dispatch
   object, which loses the method flags. Store `out = root.Output` and reuse it.
3. **Arrays and output arguments are passed as VARIANT by reference**, for example
   `VARIANT(pythoncom.VT_BYREF | pythoncom.VT_ARRAY | pythoncom.VT_R8, [0.0] * 6)`, then read
   `.value`.
4. **Sizes carry float noise**: 0.6 m gives 600.0000222 mm. Round them, or the engine's NA sweep
   can add a spurious curve point (fixed in the engine too).
5. **End forces flip sign at the end node**: +Fx is compression at the start node, −Fx at the
   end node. Intermediate forces are already compression-positive everywhere.
6. **Members drawn top-to-bottom** have local x pointing down. Label ends Top/Bottom by node
   elevation, not start/end.
7. Axis mapping (rectangle): **Mz ↔ YD, My ↔ ZD** (confirmed with STAAD's Iz = ZD·YD³/12).

## 5. Connection to Excel

**Writing workbooks: `openpyxl`, no Excel needed.** The sheet builders in `design_docs\` write
live formulas, styles, conditional formats, charts and the logo. `design_docs\edrc_sheet.py`
holds the EDRC company format. It is a project copy of the design-calculation skill module with
two local fixes: multi-letter columns (AE, AJ…) and several sheets in one workbook (`wb=`).
Status fills set both `fgColor` and `bgColor`, because Excel ignores `fgColor` in conditional
formats and UNSAFE was otherwise invisible.

**Recalculating and exporting PDF: Excel through COM (pywin32).** Excel 2016+ is installed at
`C:\Program Files\Microsoft Office\root\Office16\EXCEL.EXE`. LibreOffice is **not** installed,
so Excel does the recalculation. In `column_tool\report.py`:

```python
pythoncom.CoInitialize()
xl = win32com.client.DispatchEx("Excel.Application")   # separate instance, not the user's open Excel
xl.Visible = False
xl.DisplayAlerts = False
wb = xl.Workbooks.Open(os.path.abspath(path))
xl.CalculateFull()          # writes cached values so viewers see numbers
wb.Save()
wb.ExportAsFixedFormat(0, os.path.abspath(pdf_path))   # 0 = PDF, all sheets, uses print areas
wb.Close(False)
xl.Quit()
```

If the target .xlsx is open in Excel, saving fails with a `PermissionError`, and the tool asks
you to close the file.

A standalone PowerShell version of the same thing, used while developing. It also counts
formula errors; this copy lives in the session scratch folder, not in the project:

```powershell
param([string]$Xlsx, [string]$Pdf)
$xl = New-Object -ComObject Excel.Application
$xl.Visible = $false
$xl.DisplayAlerts = $false
try {
    $wb = $xl.Workbooks.Open($Xlsx)
    $xl.CalculateFull()
    $ws = $wb.Worksheets.Item(1)
    $errs = 0
    foreach ($c in $ws.UsedRange.Cells) { if ($c.Text -like '#*' -and $c.Text -ne '#N/A') { $errs++ } }
    Write-Output "errors (excluding #N/A plot helpers): $errs"
    $wb.Save()
    if ($Pdf) { $ws.ExportAsFixedFormat(0, $Pdf) }
    $wb.Close($true)
} finally {
    $xl.Quit()
    [System.Runtime.InteropServices.Marshal]::ReleaseComObject($xl) | Out-Null
}
```

PowerShell **script execution is disabled** on this PC (`running scripts is disabled`). To run
a .ps1, use `powershell -ExecutionPolicy Bypass -File script.ps1 …`, or run the commands
directly.

## 7. Workflow: run → check → report error → fix → re-run

1. **Run the .bat**, by double-clicking it (or `run_column_tool.bat` with STAAD open and
   columns selected).
2. **Check the result**:
   - App or tool: the window opens; groups show SAFE/UNSAFE with a reason line.
   - Sheet builders: the console prints `saved …xlsx`. Open the file in Excel and look for
     `#` errors, MISMATCH stamps, or UNSAFE verdicts.
   - Report: the result box lists the .xlsx and .pdf. Open the PDF and check the layout.
3. **If something fails, report the error**: the `if errorlevel 1 pause` / `BUILD FAILED`
   lines keep the console open. Copy the full traceback, or send a screenshot of the window,
   together with what you did, for example "selected members 1 and 3, filter 1-4, clicked
   Generate".
4. **Code is fixed.** The fix comes with a regression test where possible, and then:
   - `pytest -q` (all tests green), `flake8`, and `mypy src` are run;
   - for UI fixes: a headless run (`QT_QPA_PLATFORM=offscreen`, with
     `QT_QPA_FONTDIR=C:\Windows\Fonts` so text renders, and `QMessageBox` patched so modal
     dialogs don't block), with a screenshot saved via `widget.grab().save(...)`;
   - for sheet fixes: build → Excel recalc (0 formula errors) → PDF → render the pages and look;
   - numbers are cross-checked independently, for example the sheet against the Python core
     (≤ 0.1 %), and Pb and Puz by hand calculation.
5. **Re-run the same .bat** and confirm the problem is gone. Source runs (`run_app.bat`,
   `run_column_tool.bat`, the sheet .bats) pick up the fix straight away. **Only the .exe
   needs `build_exe.bat` again.** Close and reopen a running tool window to load new code.

## 8. Checklist for a new project

1. `py -3.13 -m venv .venv`, then install the packages in §3.
2. Copy the .bat patterns from §2; keep `cd /d "%~dp0"` and the quoted venv Python path.
3. For a package entry point, add `__main__.py` and run it with `python -m <package>`.
4. STAAD: copy `MySTAADLibrary\` and follow the gotchas in §4 (method flags, cached
   sub-objects, VARIANT byref arrays, rounding sizes).
5. Excel: openpyxl to write; Excel COM (`DispatchEx`) to recalculate and export the PDF. Set
   both `fgColor` and `bgColor` on conditional-format fills.
6. Add `pyproject.toml` with the pytest `pythonpath = ["."]` and tool settings, and a tests
   folder, before the first fix cycle.
